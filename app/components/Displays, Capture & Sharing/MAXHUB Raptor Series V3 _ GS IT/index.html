Features

Large Picture, Built-In Intelligence

Large rooms get a bright, detailed picture and complete meeting tools from one integrated display.

Sizes from 120″ to 220″

Ten models cover screen sizes from 120″ up to 220″, with 4K options at 162″ and 220″.

Android 13 Built In

An octa-core processor with 8GB of RAM and 64GB of storage runs the built-in apps.

Wireless Sharing

Laptops and phones can share through MAXHUB Share, Miracast, Chromecast or AirPlay.

Six-Driver Speakers

The display has a built-in speaker system with six chambers and six drivers.

Four HDMI Inputs

Picture-by-picture, picture-in-picture and picture-on-picture layouts combine several sources.

Automatic Brightness

Built-in light sensors adjust the screen brightness to the room.

Overview

One Display, Many Platforms

Teams, Zoom, Webex and Google Meet can all run on the display. An optional LMT71A PC module adds Windows alongside Android.

  • Q-SYS, Extron and other control systems can integrate with the display.
  • An RS232 port on an RJ45 connector supports central control.
  • Settings can be adjusted over Wi-Fi, a network cable or USB.
  • The HDMI 2.0 output drives a second screen with different content.
  • Standby power stays at 0.5W or less.
Security & Management

Protected Files & Remote Device Care

IT staff can decide what reaches the display and look after it from a distance.

USB Access Control

Unauthorised file imports and copies over USB can be blocked.

Hotspot Permissions

Hotspot permissions and device connections can be controlled for each display.

Separate System Networks

With the optional PC, Android and Windows run on separate networks.

Startup & Input Rules

Startup content, input priority and HDMI wake-up can be set per room.

Remote Management

A central platform handles remote upgrades, screen control, message publishing and app installation.

FAQs

Common Questions on Raptor Series V3

01What is the difference between the SMD and COB models?

The COB models use flip chip COB LEDs with 15000:1 contrast, 165° viewing angles and a 31mm cabinet. The SMD models have 6500:1 contrast, 160° by 140° viewing angles and a 28mm cabinet.

02Which models offer 4K resolution?

The LX220V18 and the LX162V18C run at 3840 × 2160. The LX162V15C runs at 2880 × 1620, and the other models run at 1920 × 1080.

03Can the display run Windows?

Yes. The optional LMT71A PC module adds Windows, and the display keeps its built-in Android 13 system.

04Which video conferencing platforms are supported?

The display supports platforms such as Microsoft Teams, Zoom, Webex and Google Meet.

05Can a camera be powered from the display?

On the SMD models, an internal PoE+ port supplies up to 30W to a MAXHUB PTZ camera.

06How is the display maintained?

All service is done from the front, and modules can be hot-swapped with the supplied maintenance tool.

07How can it be installed?

It can be wall-mounted with the supplied bar. Many models also work with an optional ST90 or ST92 stand.

08Can it be used outdoors?

No. It is an indoor product and should be kept out of direct sunlight.
